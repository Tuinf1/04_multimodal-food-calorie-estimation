# План проекта: предсказание калорийности блюд

## Цель

Создать мультимодальную модель, которая предсказывает общую калорийность блюда по фотографии, списку ингредиентов и массе порции.

Главная метрика:

```text
MAE < 50 ккал
```

Официальная тестовая выборка используется только для итоговой оценки модели.

## Последовательность работы

### 1. Подготовить окружение

- Создать и активировать `.venv`.
- Установить зависимости из `requirements.txt`.
- Проверить импорт библиотек, доступность CUDA и работу GPU.

Статус: готово.

### 2. Подготовить данные

- Загрузить `dish.csv` и `ingredients.csv`.
- Заменить идентификаторы ингредиентов их названиями.
- Сформировать пути к изображениям.
- Проверить пропуски, дубликаты и наличие изображений.

Статус: готово.

### 3. Разделить выборки

- Сохранить официальный test без изменений.
- Разделить исходный train на внутренние train и validation.
- Зафиксировать `random_state`, чтобы разделение воспроизводилось.

Статус: готово. Получено 2204 объектов train, 551 validation и 507 test.

### 4. Провести EDA

- Изучить распределения калорийности и массы.
- Рассчитать калорийность на 100 г.
- Проверить связь массы и калорийности.
- Изучить количество и частоту ингредиентов.
- Посмотреть примеры фотографий и выбросы.

Статус: готово.

### 5. Построить простые модели

- Предсказание медианой.
- Линейная регрессия по массе.
- Ridge по ингредиентам и массе.

Полученные результаты на validation:

| Модель | Validation MAE |
|---|---:|
| Median | 166.80 |
| Mass Linear Regression | 105.13 |
| Ingredients + Mass Ridge | 50.04 |

Статус: готово. Лучшей простой модели не хватило 0.04 ккал до целевого уровня.

### 6. Создать мультимодальную модель

Создать `scripts/model.py` с тремя ветками:

- image encoder получает признаки из фотографии;
- text encoder получает признаки из списка ингредиентов;
- небольшой полносвязный блок обрабатывает массу.

После объединения признаков регрессионная голова предсказывает одно число - общую калорийность блюда.

Первый вариант:

- EfficientNet-B0 для изображения;
- DistilBERT для текста;
- небольшой MLP для массы;
- замороженные предобученные энкодеры на первом запуске.

Статус: следующий этап.

### 7. Создать обучение модели

Создать `scripts/train.py`, который выполняет:

- обучение по эпохам;
- расчёт validation MAE;
- mixed precision для экономии памяти;
- сохранение лучшей модели;
- early stopping;
- сохранение истории обучения.

Для первого запуска использовать batch size 4 и изображения 224 x 224.

### 8. Проверить весь пайплайн

- Выполнить forward pass на одном batch.
- Проверить вычисление loss и backward pass.
- Попробовать переобучить модель на 16-32 объектах.
- Провести короткий запуск на одной эпохе.

Полное обучение начинаем только после успешного прохождения этих проверок.

### 9. Обучить и выбрать лучшую модель

- Сначала обучить модель с замороженными энкодерами.
- При необходимости разморозить последние блоки image encoder.
- Сравнивать модели только по validation MAE.
- Менять за один эксперимент один существенный параметр.

### 10. Оценить модель на test

- Загрузить лучший checkpoint.
- Получить предсказания на официальном test.
- Рассчитать итоговый MAE.
- Показать пять блюд с самыми большими ошибками.
- Объяснить возможные причины ошибок.




## Итоговая модель с поправкой к Ridge

1. Создать отдельный файл `scripts/train_residual.py`. Существующий `scripts/train.py` не изменять.

2. Создать `config_residual.yaml` с параметрами обучения итоговой модели.

3. Обучить Ridge на ингредиентах и массе. Для обучающей выборки использовать OOF-прогнозы, чтобы избежать утечки данных.

4. Загрузить веса нейросети из `artifacts/best_model_finetuned.pt`.

5. Обучить нейросеть предсказывать поправку к прогнозу Ridge:

   `итоговый прогноз = прогноз Ridge + поправка нейросети`

6. Сохранить две части итоговой модели:

   - `artifacts/ridge_residual.joblib`
   - `artifacts/best_model_residual.pt`

7. Проверить итоговую модель на validation. Если результат лучше `45.47`, выполнить последнюю проверку на test и сравнить с целевым значением `MAE < 50`.

- Проверить запуск проекта из корневой папки.

## Текущая точка

Этапы 1-5 завершены. Сейчас переходим к этапу 6 - созданию мультимодальной модели в `scripts/model.py`.

## Общая схема

```text
Фотография -> image encoder ----\
                                  \
Ингредиенты -> text encoder ------> объединение -> MLP -> калорийность
                                  /
Масса -> небольшой MLP ----------/
```
