## Памятка по GPU с 16 ГБ VRAM

- Начальный размер изображения - 224 x 224.
- Начальный batch size - 4.
- Gradient accumulation - 4 шага, эффективный batch size - 16.
- Использовать mixed precision FP16.
- Максимальная длина текста - 64 токена.
- На первом этапе заморозить text encoder и большую часть image encoder.
- Размораживать последние блоки энкодеров постепенно.
- Использовать `optimizer.zero_grad(set_to_none=True)`.
- Для validation использовать `torch.inference_mode()`.
- Стараться удерживать расход VRAM в пределах 12-14 ГБ.
- При OOM сначала уменьшить batch size до 2, затем заморозить text encoder и уменьшить изображение до 192 x 192.
