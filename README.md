# Предсказание калорийности блюд

Проект по предсказанию общей калорийности блюда по фотографии, составу ингредиентов и массе порции. Целевая метрика — `MAE < 50` ккал на официальной test-выборке.

## Результат

| Модель | MAE, ккал |
| --- | ---: |
| Ridge: ингредиенты + масса, validation | 50.04 |
| EfficientNet-B0 после fine-tuning, validation | 43.57 |
| Итоговая модель, validation | **34.10** |
| Итоговая модель, test | **47.76** |

Целевая метрика достигнута: `47.76 < 50`.

## Данные

Модель использует:

- RGB-фотографию блюда;
- текстовый список ингредиентов;
- общую массу порции.

Датасет должен быть расположен в `data/`:

```text
data/
├── dish.csv
├── ingredients.csv
└── images/
    └── <dish_id>/rgb.png
```

Официальная test-выборка не используется для обучения. Из исходного train-сплита формируются train и validation в соотношении 80/20 со стратификацией по калорийности.

## Итоговая модель

Итоговый прогноз состоит из двух частей:

```text
Итоговый прогноз = прогноз Ridge + нейросетевая поправка
```

1. **Ridge-регрессия** использует набор ингредиентов, нормализованную массу и признаки `ингредиент × масса`. Они позволяют модели по-разному учитывать массу продуктов с разной энергетической плотностью.
2. **Мультимодальная нейросеть** обрабатывает фотографию с помощью EfficientNet-B0, текст ингредиентов с помощью DistilBERT и массу блюда. Она предсказывает поправку к прогнозу Ridge.

Для train-объектов Ridge использует OOF-прогнозы, поэтому нейросетевая поправка не обучается на переобученных прогнозах Ridge.

```text
project.ipynb                 # EDA, обучение, оценка и визуализация ошибок

scripts/
```

## Установка

Требуется Python 3.12 и NVIDIA GPU для обучения.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

Откройте `project.ipynb` и выполните ячейки сверху вниз. Для отдельного запуска итоговой модели выполните в ноутбуке:

```python
from scripts.train_residual import train_residual

history_residual_mass = train_residual(
    "config_residual_mass.yaml"
)
```

Для обучения нейросетевой поправки нужен checkpoint базовой модели `artifacts/best_model_finetuned.pt`, который создаётся после этапов обучения в ноутбуке.

## Анализ ошибок

Наибольшие ошибки модели возникают для блюд со скрытыми высококалорийными компонентами: маслом, сыром, орехами, соусами и тестом. Их количество и способ приготовления трудно определить по фотографии и списку ингредиентов.
